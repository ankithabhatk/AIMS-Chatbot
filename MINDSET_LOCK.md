## The Only Mistake You Can Make

**Premature fixing**

You see 2-3 bad queries and think:
```
"Let me quickly fix this"
```

- Messy rules
- Conflicting logic
- System instability

**Don't do this.**

## What to Look For (Super Practical)

### Pattern 1: Repeated Words You Didn't Expect
```
"cost"
"price"
"how much"

→ That's ONE fix later.
```

### Pattern 2: Repeated Sentence Styles
```
"i like coding what should i do"
"which course is best for me"

→ That's ONE handler later.
```

### Pattern 3: Obvious Wrong Behavior
```
fees → shows form (wrong)

→ That's ONE routing fix later.
```
