## Your Governance Model

## The Three Buckets

### 🟢 Bucket 1: Keyword Gaps
**Problem**: User says "cost", system doesn't detect as "fees"  
**Fix**: Add keyword  
**Governance**: 3+ occurrences  

### 🟡 Bucket 2: Phrase Patterns
**Problem**: User says "how much does it cost", system doesn't detect intent  
**Fix**: Add phrase pattern  
**Governance**: 5+ occurrences  

### 🔴 Bucket 3: Intent Transformation
**Problem**: User says "I like coding what should I choose", system routes wrong  
**Fix**: Add query type handler  
**Governance**: 3+ occurrences AND causes failure

## User Struggle Tracking

### What You'll Track
Not just queries, but patterns of repeated attempts:

```
User sends:
1. "fees"
2. "bca fees"
3. "what is fee"

This is 1 FAILED interaction (not 3 queries)
```

### Why It Matters
Struggle patterns show:
- What users really want
- Where system is confusing
- What to prioritize fixing
