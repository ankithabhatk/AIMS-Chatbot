## ⚠️ Critical Context

**Current Phase:** RAG Implementation (COMPLETE ✅)

**Next Phase:** Data & Integration
- Database persistence (PostgreSQL + pgvector)
- Lead capture endpoint
- Real website scraping

**Key Constraints:**
- ✅ No external APIs for MVP (local-first)
- ✅ Sentence-Transformers embeddings (384-dim, local)
- ✅ FAISS vector search (no Pinecone)
- ✅ Template-based responses (deterministic, no hallucinations)
- ✅ FastAPI async backend
- ✅ Modular service architecture

**Identified Risks:**
1. Website scraper fragility (HTML changes)
2. FAISS single-machine limitation
3. Template responses may need LLM
4. No database persistence yet
5. Salesforce integration not started
