### 1. Deploy (No More Changes)
```

```

### 2. Collect 50 Real Queries
```
Not test queries.
Not synthetic.

Real users saying:
- "bro fees kitna hai"
- "hostel hai kya"
- "is this college good or not"
- "i like coding what to do"

```

### 3. Extract Top 3 Patterns
```
After 50 queries, find:

Pattern A: Language gap
Example: "cost" not mapped to fees

Pattern B: Phrase gap
Example: "how much does it cost"

Pattern C: Routing mistake
Example: fees + hostel → wrong response

Fix ONLY these.
```
